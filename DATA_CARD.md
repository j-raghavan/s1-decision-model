# s1-decision-data

The training data of [s1-gemma4-26b-decision](https://huggingface.co/j-raghavan/s1-gemma4-26b-decision), an open,
calibrated decision model: **101,292 typed decision rows** with soft targets, plus the custom evaluation sets. Every
row is from a permissively licensed public dataset, a rule generator, or a synthetic generator, and carries its own
licence. Code that builds it: [github.com/j-raghavan/s1-decision-model](https://github.com/j-raghavan/s1-decision-model)
(`pipeline/`, `scripts/build_dataset.py`).

## What a row looks like

`state`, `question`, `target`, `teacher_calibrated` and `provenance` are stored as JSON text so every row has the same
schema; decode them with `json.loads`:

```python
import json
from datasets import load_dataset

rows = load_dataset("j-raghavan/s1-decision-data", split="train")
row = {k: (json.loads(v) if k in ("state", "question", "target", "teacher_calibrated", "provenance") and v else v)
       for k, v in rows[0].items()}
```

Decoded, a row looks like this:

```json
{
  "row_id": "aqua_math-3812",
  "family": "aqua_math",
  "task_type": "choice",
  "state": {"...": "the text or JSON the decision is about"},
  "question": {"type": "choice", "instructions": "...", "criteria": {"a": "...", "b": "..."}},
  "gold": "b",
  "target": {"a": 0.028, "b": 0.739, "c": 0.023, "d": 0.097, "e": 0.114},
  "gold_weight": 0.7,
  "holdout_family": false,
  "teacher": "google/gemma-4-26B-A4B-it",
  "teacher_calibrated": {"a": 0.094, "b": 0.128, "c": 0.075, "d": 0.323, "e": 0.379},
  "teacher_conflict": false,
  "license": "Apache-2.0",
  "provenance": {"source": "AQuA-RAT", "hub_id": "deepmind/aqua_rat", "source_row": 50970}
}
```

| Field | Meaning |
| --- | --- |
| `task_type` | `choice` (one of keyed options), `noul` (yes/no, keys `true`/`false`), `score` (ordinal, keys are level indices) |
| `state`, `question` | the model input; `question.criteria` holds the options |
| `gold` | the source dataset's (or rule generator's) answer |
| `target` | the soft target the model was trained on: `gold_weight * one_hot(gold) + (1 - gold_weight) * teacher_calibrated` |
| `teacher_calibrated` | the teacher's option distribution, calibrated per task family (2-fold cross-fitted); null for gold-only rows |
| `gold_weight` | how much the gold label counts: 0.9 rule-generated, 0.7 objective answer keys and consensus-filtered synthetic rows, 0.6 Super-NaturalInstructions, 0.5 subjective or crowd-noisy labels; injection and held-out rows are gold only |
| `teacher_conflict` | the teacher put little probability on the gold answer (kept, flagged for audit) |
| `holdout_family` | whole task families held out for validation of unseen instructions (1,735 rows) |
| `license`, `provenance` | the row's source licence and where it came from |

At training time options are reshuffled per example (except ordinal scales) and rendered with letters; see
`s1/decoder.py` in the repository for the exact prompt.

## How it was made

1. **Conversion.** Public datasets become typed questions (`pipeline/sources.py`); Super-NaturalInstructions tasks
   were kept only if English, with 2–20 fixed answers, a permissive instance licence, and no source shared with an
   evaluation set (`pipeline/sni_manifest.json` lists every inclusion and exclusion).
2. **Generators.** `pipeline/structured.py` writes structured decisions whose answer is exact by construction.
   `pipeline/generate_synthetic.py` asks `openai/gpt-oss-120b` for task families (a policy, a state shape, instances);
   a generated answer is kept only where `google/gemma-4-26B-A4B-it` independently agrees.
3. **Prompt injection.** Attack prompts from SPML, Gandalf and LLMail-Inject, with benign intent questions as
   negatives (`pipeline/injection.py`), 9.6% of the mix.
4. **Teacher labels.** `google/gemma-4-26B-A4B-it` in bf16 through vLLM 0.31.0, prompts starting with `<bos>`, reads
   the option distribution in one forward pass (`pipeline/label.py`); calibration and blending in `pipeline/targets.py`.
5. **Deduplication.** Evaluation dev splits were deduplicated against the test sets and these rows; an exact-text check
   of every row against every JevBench case and the custom test set found no overlap.

### About the targets in this release

The training session built its soft targets on the GPU and did not keep them. The targets here were **regenerated**
afterwards by repeating that exact step with the same code, rows, model and serving stack
(`colab/session_relabel.py`). They match the originals closely but not bit for bit: row-weighted teacher-gold
agreement is 0.8398 against 0.8397 in the training run, about 0.3% of rows changed their top answer (near-ties under
GPU numerics), and the synthetic consensus filter kept one row fewer (90,134 core rows against 90,135). The input rows,
gold labels, gold weights and the 11,335 gold-only rows are exactly those trained on.

177 training rows from Super-NaturalInstructions task 289 (Gigaword summarisation) are **not redistributed**: the task
is marked MIT, but its text comes from a newswire corpus whose licence could not be verified.

## Licence

Mixed, all permissive: each row's `license` field gives its source licence, and the row stays under it. Share-alike
rows (CC-BY-SA, 16,670 rows) must stay under their share-alike licence when redistributed; attribution for CC-BY
sources is in [ATTRIBUTION.md](ATTRIBUTION.md). Rows written by this project's generators are Apache-2.0. OANC rows
(1,266, from MultiNLI via Super-NaturalInstructions) can be treated as CC-BY-SA-3.0 to be conservative.

## Limitations

- English only. Sources carry their own biases (crowd-written NLI, toxicity annotations, web text).
- Teacher-derived targets inherit the teacher's errors; `teacher_conflict` flags rows where the teacher disagreed
  sharply with the gold answer.
- Injection rows include real attack prompts; they are labelled as such and meant for training detectors.
